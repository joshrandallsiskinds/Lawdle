# CanLIIDLE

A daily Canadian case law deduction game. Use legal clues to identify landmark Canadian appellate decisions.

## GitHub Pages Deployment

1. Push this repository to GitHub as `joshrandall/canliidle`.
2. In the repository, open **Settings → Pages** and select the deployment branch and `/ (root)` folder.
3. GitHub Pages publishes the self-contained `index.html` without a server, build step, dependencies, or authentication.

**GitHub Pages URL:** <https://joshrandall.github.io/canliidle/>

Share this URL with beta testers. The game link and result-sharing actions use this project-site URL, including the `/canliidle/` repository subfolder.

The application uses browser-local storage for progress, preferences, and anonymous gameplay statistics. No GitHub account is required to play.
